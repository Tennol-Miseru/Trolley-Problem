# 电车难题模组｜完整玩法说明

> **Trolley Problem / 电车难题** · 适用版本：**r22.8.1**  
> Minecraft Java **1.21.1** · **NeoForge**（工程使用 21.1.244）· Java **21**

前方有一辆失控的电车。你有两个选择：拉杆，或者再召唤一辆电车。

本模组加入了随机电车难题、可驾驶电车、创飞与碰碰车对战、伦理学家、白色终点站次元和至尊电车 BOSS。你可以认真思考道德困境，也可以把整个实验现场变成交通事故。

## 一、安装与入门

1. 使用 Minecraft Java 版 1.21.1 和对应的 NeoForge，推荐使用与工程一致的 NeoForge 21.1.244。
2. 将编译生成的 `mod_e539c988-*.jar` 放入游戏的 `mods` 文件夹；删除旧版同 Mod ID 的 JAR，避免重复加载。
3. 联机时，服务器及所有参与玩家应安装**同一版本的模组**，并尽量统一 NeoForge 版本。
4. 备份已有世界后再升级模组。首次游玩可以先开创造模式熟悉物品，或通过难题进度获取奖励。

模组道具主要位于创造物品栏的「工具与实用物品」；生物伦理学家召唤蛋位于「刷怪蛋」。

## 二、随机电车难题：15 秒，两个方向

世界中可以遇到随机生成的轨道难题，也可以用指令手动召唤。

1. 靠近已经生成的难题装置（约 22 格内），触发 **15 秒倒计时**。
2. 阅读聊天提示，观察红、绿两条轨道上的被困生物。
3. 操作现场拉杆：**开启（ON）→ 红色轨道；关闭（OFF）→ 绿色轨道**。
4. 电车发车时锁定当时的拉杆状态；之后会公布选择、幸存和死亡数量。
5. 靠近并完成实验可积累个人奖励进度；旁观模式玩家不获得奖励。

### 当前八种难题

| 题型 | 红色轨道 | 绿色轨道 |
|---|---|---|
| `classic` 经典 | 1 名普通村民 | 5 名普通村民 |
| `cat` 猫咪 | 1 只猫 | 5 名普通村民 |
| `dog` 忠犬 | 1 只狼（狗） | 5 名普通村民 |
| `pets` 猫狗 | 1 只狼 | 5 只猫 |
| `creeper` 苦力怕 | 1 只苦力怕 | 5 名普通村民 |
| `criminal` 犯罪与救赎 | 1 名「医生」村民 | 5 名「杀人犯」村民 |
| `child` 年龄 | 1 名儿童村民 | 5 名成年村民 |
| `mending` 经验修补 | 1 名经验修补图书管理员 | 5 名普通村民 |

**经验修补难题**取代旧「村长难题」。图书管理员拥有实际交易：**20 颗绿宝石 + 1 本书 → 经验修补 I 附魔书**；若存活，仍可与其交易。旧存档里保留的 `mayor` 题型标识会映射为 `mending`。

### 难题奖励

同一轮个人进度达到：

- **3 次**：电车方向盘
- **5 次**：电车拉杆
- **10 次**：狂野拉杆，随后进度重置，进入下一轮

奖励以场景附近 **32 格**内的参与玩家为单位结算；背包满时奖励会掉在玩家附近。使用 `/trolleyproblem progress` 可查看当前进度。

## 三、召唤电车与道具

| 物品 | 用途 |
|---|---|
| **电车拉杆** | 召唤向前疾驰的普通电车；被撞到的生物可能被直接撞死 |
| **狂野拉杆** | 召唤会寻找附近目标并改变行驶方向的电车 |
| **创飞电车拉杆** | 召唤强力击飞电车；一次有效命中造成 **8 点基础伤害（4 颗心）**和夸张击退 |
| **电车方向盘** | 召唤可驾驶电车并自动上车 |
| **至尊拉杆（皮搋子）** | 在面前召唤从天而降的巨型电车；冷却约 **3 秒** |
| **生物伦理学家召唤蛋** | 召唤会对电车事故发表评论的特殊村民 |
| **空白车票** | 在主世界与白色终点站之间往返的快捷道具 |
| **电车方块** | 建造白色终点站传送门的框架材料 |

**召唤模式切换**：站在地上、手持上述可召唤电车的拉杆或方向盘时，按 **Shift + 右键**在「虚空模式」与「实体模式」间切换，随后正常右键召唤。

- **虚空模式**：电车可以穿过方块，行驶不受重力影响。
- **实体模式**：电车会与方块碰撞并受到重力影响。
- 切换结果会显示在快捷栏提示中；不同召唤道具有自己的默认模式。

普通非驾驶电车对**同一名玩家**至多判定一次致命撞击；创飞拉杆召唤的同一辆电车对同一目标也只结算一次创飞伤害。创飞击中玩家会给予缓降保护，击中普通生物**不会**给予缓降。

## 四、驾驶操作与碰碰车 PvP

使用**电车方向盘右键**可召唤并立即乘坐自己的电车；已有的无人驾驶电车也可以右键上车。

| 操作 | 功能 |
|---|---|
| `W` / `S` | 前进、减速 / 倒车 |
| `A` / `D` | 转向 |
| `V` | 切换「创飞模式」与「普通驾驶模式」 |
| `Shift` | 下车（原版操作） |

驾驶电车**默认开启创飞模式**。创飞撞击普通生物或玩家造成 **8 点基础伤害**并将其击飞；驾驶创飞攻击同一目标的间隔约为 **26 游戏刻**。V 键可在游戏「按键绑定」中自定义。驾驶中**不使用** Shift + 右键切换创飞，因为 Shift 会让玩家下车。

### 双人碰碰车怎么玩？

让两名玩家分别驾驶电车，相向冲锋或侧向碰撞即可：

- 只有**两辆都由玩家驾驶**的电车参与车辆对撞，且至少一辆车正在运动。
- 车辆按可见车身轮廓判定接触，而不只按很窄的驾驶碰撞箱判定。
- 撞击会产生爆炸粒子、音效和双车反弹，同时扣除车辆耐久。
- 每辆电车起始为 **40 点耐久**，碰撞强度随速度和状态变化；耐久归零即爆炸淘汰。
- 车辆爆炸只造成视觉效果，**不会炸坏地形**；驾驶员会弹出并获得短暂的电车撞击保护。
- 两次有效车辆碰撞之间存在约 **34 游戏刻**的冷却，避免贴在一起时每刻扣血。
- 正常被破坏和碰碰车淘汰的电车会掉落 **14 个电车方块**；自然消失不掉落。

驾驶电车静止时不再循环播放行驶音效。下车后，如果 **15 秒**没有人再次驾驶，电车会自动回收消失。

**联机建议**：服务器和客户端必须使用同版本 JAR。同机双开时，为两个实例设置不同的游戏目录，避免日志、资源及存档访问冲突。

## 五、白色终点站次元

### 进入方法一：建造电车传送门

收集被破坏电车掉落的**电车方块**，搭建类似下界传送门的框架：

- 推荐框架：**外框宽 4 格、高 5 格**，完整边框需要 **14 个电车方块**；
- 也支持完整的 **4×4** 小型边框（边框需要 12 个电车方块）；
- 框架内部保持空置，用**打火石**在框架内部点燃即可生成传送门；
- 在主世界穿过传送门，进入白色终点站。到达站台也设有返回传送门。

### 进入方法二：空白车票

将 **1 张纸**放在工作台中央，上、下、左、右各放 **1 个铁粒**，合成「空白车票」。在**主世界**右键车票进入白色终点站；在终点站内使用则返回主世界。

### 次元里有什么？

纯白空间、城市建筑、站台、长铁路、铁路电线及设施、站台广播、驶过的电车和空中掠过的列车。沿站台延伸至 BOSS 竞技场的铁路线前进，可以寻找**至尊电车**（竞技场大致位于 `X=0, Z=256`）。

## 六、至尊电车 BOSS

- BOSS 具有高速冲撞、二段冲撞、追踪冲锋、跳跃轰击和旋转冲锋等招式。
- 生命值随附近参战人数调整：基础 **200**，约按人数乘以 200，最高 **500**。
- 战斗阶段中会出现需要处理的**电车难题**；根据提示前往指定坐标，完成后继续作战。
- 击败后掉落 **至尊拉杆（皮搋子）**和**空白车票**。
- 至尊拉杆右键可召唤一辆从天而降的巨型电车；具有 **3 秒**冷却。

至尊电车为该存档的白色终点站设计的特殊首领。升级模组前建议备份包含次元的存档。

## 七、指令速查

```mcfunction
/trolleyproblem spawn
/trolleyproblem spawn classic
/trolleyproblem spawn cat
/trolleyproblem spawn dog
/trolleyproblem spawn pets
/trolleyproblem spawn creeper
/trolleyproblem spawn criminal
/trolleyproblem spawn child
/trolleyproblem spawn mending
/trolleyproblem progress
/trolleyproblem enter
/trolleyproblem leave
```

- `/trolleyproblem spawn` 随机生成一道难题；也可指定题型。**生成类指令要求管理员权限（权限等级 2）**，生成位置需要有足够空间。
- `/trolleyproblem progress` 查询个人当前十次循环的进度。
- `/trolleyproblem enter` / `leave` 用于进入或离开终点站，仍须满足对应维度条件。
- 旧 `/trolleyproblem spawn mayor` **已不再是新的可用指令**；用 `mending` 替代。
